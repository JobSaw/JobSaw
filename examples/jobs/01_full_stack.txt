FICTIONAL TEST JOB: Senior Full Stack Engineer
Company: ShopBridge Commerce
Location: Remote, Europe

We build e-commerce software for independent retailers. Join a product squad
with frontend/backend engineers, a designer, and a product manager. Your main
focus is customer-facing web applications and integrations, not infrastructure.

Responsibilities
- Build React interfaces and Node.js services using TypeScript and JavaScript.
- Design REST APIs and GraphQL endpoints for checkout and order management.
- Integrate payment gateways and troubleshoot failed payment flows.
- Build live inventory updates using WebSockets.
- Optimize PostgreSQL queries and maintain MongoDB-backed features.
- Write Jest tests, review code, and mentor junior developers.
- Collaborate with design and product colleagues in Agile / Scrum delivery.

Required qualifications
- At least five years of professional web-development experience.
- Strong React, TypeScript, JavaScript, Node.js, and REST API Design skills.
- Experience with PostgreSQL, MongoDB, WebSockets, and automated testing.
- Clear technical communication, mentoring, and collaborative problem solving.

Preferred
- GraphQL, Redis caching, Docker, and Git-based delivery workflows.
- E-commerce, payment integrations, and migration from monoliths to services.

Infrastructure operations and game development are not part of this role.
